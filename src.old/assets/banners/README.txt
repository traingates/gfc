EVENT BANNERS
=============
Drop a banner image here named after the EVENT. It appears on the main
event card (home), inside expanded history rows, and on event posters.

Naming: <event-name>.png  (or .jpg / .jpeg)
The name must match the Event name you typed in the admin panel.

Examples:
  Event "GFC 5: Firestorm"  ->  gfc-5-firestorm.png
  Event "Night of Champions" -> night-of-champions.jpg

Recommended size: wide, roughly 1200 x 400 px.
If no matching file is found, no banner shows (nothing breaks).
After adding files, redeploy the site.
