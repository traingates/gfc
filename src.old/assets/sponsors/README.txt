PARTNER / SPONSOR LOGOS
=======================
Drop a logo file here named after the sponsor, lowercased with hyphens
instead of spaces. The site finds it automatically — no code editing.

Naming: <sponsor-name>.png  (or .jpg / .jpeg)
The name must match the sponsor you added in the admin panel.

Examples:
  Sponsor "Acme Corp"      ->  acme-corp.png
  Sponsor "Nova Energy!"   ->  nova-energy.png
  Sponsor "Redstone Labs"  ->  redstone-labs.jpg

If no matching file is found, the sponsor's name shows as text instead.
Transparent PNGs look best. After adding files, redeploy the site.
